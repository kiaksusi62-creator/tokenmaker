🚀 Crypto Builder Platform - Das Krypto-Aufbau Spiel
===================================================

Ein interaktives Browserspiel, bei dem du dein eigenes Krypto-Imperium aufbaust!

## 🎮 Spielfeatures

### 💼 Token Builder
- **Erstelle Tokens**: Designiere deine eigenen Kryptowährungen mit Namen, Symbol, Supply und Kategorie
- **Kosten**: $500 pro neuer Token-Kreation
- **Kategorien**: Tech, DeFi, Gaming, NFT, Utility
- **Marktpräsenz**: Deine Tokens erscheinen sofort auf dem Markt

### 📈 Marktplatz
- **Hunderte von Tokens**: Kaufe und verkaufe vordefinierte Markt-Tokens und deine eigenen
- **Echte Preisvolatilität**: Realistische Preisbewegungen basierend auf Marktsimulation
- **Suchfunktion**: Finde Tokens nach Name oder Symbol
- **Sortieroptionen**: Trending, Preis, Volumen
- **Handelsvolumen**: Sehe das Handelsaktivität jedes Tokens

### 💰 Portfolio Management
- **Bestände verfolgen**: Sehe dein gesamtes Portfolio mit Gewinn/Verlust
- **Durchschnittspreis**: Automatische Berechnung des durchschnittlichen Kaufpreises
- **Echtzeit-Updates**: Portfolio-Wert aktualisiert sich live während Marktbewegungen
- **Handelshistorie**: Verfolgung aller deiner Transaktionen

### 🏆 Achievements
Schalte Erfolge frei:
- 🎯 **Erste Schritte**: Erstelle dein erstes Token
- 💎 **Millionär**: Erreiche $1.000.000 Portfolio-Wert
- 📈 **Professioneller Trader**: Mache 50 Trades
- 🎨 **Diversifiziert**: Besitze Tokens aus 5 verschiedenen Kategorien

### 📊 Dashboard
- **Nachrichten-Feed**: Verfolge wichtige Spielereignisse und Markt-Updates
- **Markttrends**: Siehe die Top 5 trendenden Tokens
- **Spielziele**: Verfolge deine Fortschritt-Ziele
- **Schnellaktionen**: Überspringe Tage und erhalte Bonuse

## 🎯 Wie du spielst

### Schritt 1: Starten
1. Öffne `index.html` in deinem Browserfenster
2. Du beginnst mit $10.000 Balance

### Schritt 2: Token erstellen
1. Gehe zum **Token Builder**
2. Gib Name, Symbol, Supply und Startpreis ein
3. Wähle eine Kategorie
4. Bezahle $500 zum Erstellen
5. Dein Token erscheint sofort auf dem Markt!

### Schritt 3: Handeln
1. Gehe zum **Marktplatz** oder **Meine Tokens**
2. Klicke "Kaufen" auf einem beliebigen Token
3. Geben Sie die Menge ein
4. Token werden zu deinem Portfolio hinzugefügt

### Schritt 4: Verkaufen
1. Gehe zu **Portfolio**
2. Sehe deine aktuellen Positionen
3. Klicke "Verkaufen" um Gewinne zu realisieren

### Schritt 5: Wachsen
1. Überwache Markttrends
2. Nutze Marktvolatilität
3. Baue ein diversifiziertes Portfolio
4. Erreiche Achievements
5. Werde zum Crypto Millionär!

## 🎨 Spielmechaniken

### Preisvolatilität
- Preise ändern sich alle 5 Sekunden leicht
- Realistische Marktbewegungen basierend auf Zufallsfaktoren
- 24h Änderungspercentage wird berechnet

### Spielfortschritt
- **Tage**: Überspringe Tage um Marktveränderungen zu beschleunigen
- **Balance**: Dein verfügbares Geld
- **Portfolio-Wert**: Summe aller gehaltenen Tokens zum aktuellen Preis
- **Trades**: Jeder Kauf/Verkauf wird registriert

### Markt-Events
- Zufällige News-Events beeinflussen das Gameplay
- Markttrends ändern sich dynamisch
- Volatilität variiert basierend auf Marktbedingungen

## 🐛 Fehlerbehebung

### Spielstand wird nicht geladen
- Überprüfe, ob LocalStorage in deinem Browser aktiviert ist
- Versuche Cookies/Cache zu löschen

### Preise aktualisieren nicht
- Stelle sicher, dass JavaScript aktiviert ist
- Versuche die Seite zu aktualisieren

### Buttons funktionieren nicht
- Überprüfe die Browser-Konsole auf Fehler (F12)
- Versuche einen anderen Browser

## 📈 Strategien

### Aggressive Growth
- Kaufe günstige Tokens aggressiv
- Suche nach 50%+ Gewinnpotential
- Hoher Risiko, hohe Belohnung

### Conservative Portfolio
- Kaufe Markt-Coins wie BTC und ETH
- Baue langsam auf
- Niedriges Risiko, sichere Gewinne

### Trend Trading
- Folge den Trending Tokens
- Kaufe wenn Trend beginnt
- Verkaufe bevor Trend endet

### Token Creator
- Erstelle viele verschiedene Tokens
- Beobachte welche profitabel werden
- Baue dein Portfolio von deinen Tokens auf
